## The conversation on a case

Open a case and choose the **Messages** tab. Messages appear as a conversation,
your own on one side and everyone else's on the other, with the author's name
and the time each was sent.

Only the most recent messages are loaded, and the screen says so. A case with no
conversation yet reads *"No messages yet."*

To add a message, type into the **Message** field at the bottom and send. The
message is posted to Highlighter, so it is visible to everyone else on the case
— on the web as well as on mobile. If it cannot be sent, the app tells you and
leaves the text where it is.

If the conversation cannot be loaded at all, the tab shows the reason and a
**Try Again** button.

## The message inbox

The Dashboard shows the newest few messages from across your cases under
**Recent Messages**. **View All** opens the full inbox.

The inbox lists messages from every case you have access to, newest first, each
row naming the case it belongs to. Tapping a row opens that case with its
Messages tab already selected.

- **Search** narrows the inbox to matching messages. It searches the messages
  loaded so far, so scroll to load more if you are looking for something older.
- Scrolling to the end loads more messages.
- If the inbox cannot be loaded, the screen shows the reason and a **Try Again**
  button.

The Dashboard refreshes the inbox every time you return to it, so what it shows
is what has just happened rather than what was current when you last opened the
app.
